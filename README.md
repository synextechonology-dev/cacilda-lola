# Cacilda & Lola, café e bistrô

Site do bistrô em Santa Cruz do Rio Pardo (SP): cardápio geral e de almoço, pedido pelo WhatsApp (retirada ou entrega), história da casa, fotos do salão e como chegar.

```bash
npm install
npm run dev
```

- Informações do bistrô: `data/site.ts`
- Cardápios: `data/cardapio-geral.ts` e `data/cardapio-almoco.ts`
- O que falta preencher: `PREENCHER.md`
- Guia para o Claude Code: `CLAUDE.md`
- Ver pendências na tela: abra o site com `?revisao=1`
